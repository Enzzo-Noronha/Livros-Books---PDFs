# Biblioteca de Conhecimento — Noronha AI

Esta biblioteca reúne orientações operacionais e técnicas para apoiar o Noronha Studio. Os arquivos são uma base inicial: revise e atualize as informações para refletir decisões reais da empresa.

## Pastas
- `01-empresa/`: identidade, serviços e princípios.
- `02-vendas-prospeccao/`: prospecção, diagnóstico, propostas e precificação.
- `03-desenvolvimento/`: padrões de código, segurança, testes e entrega.
- `04-produtos-saas/`: modelos de requisitos e fichas dos produtos.
- `05-gestao/`: fluxo de trabalho, projetos e atendimento.
- `06-base-tecnica/`: fontes oficiais e roteiro de estudo.
- `07-marketing/`: conteúdo, posicionamento e divulgação.

## Como usar
1. Extraia o ZIP.
2. Revise os documentos e ajuste o que não representar a realidade do estúdio.
3. Remova ou anonimize dados confidenciais de clientes.
4. Para a IA consultar os documentos, implemente uma busca local/RAG. Apenas salvar arquivos numa pasta não faz o modelo conhecê-los automaticamente.
5. Ao importar conteúdo externo, confira a licença e mantenha a origem.

## Regras de atualização
- Use datas em `AAAA-MM-DD`.
- Marque decisões não confirmadas como `A DEFINIR`.
- Não registre senhas, tokens, chaves privadas ou dados pessoais desnecessários.
- Mantenha cada produto em seu próprio documento e não misture requisitos de clientes diferentes.
