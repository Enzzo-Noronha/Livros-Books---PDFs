# Trilha para Desenvolvedor Júnior
1. HTML semântico, CSS responsivo e JavaScript/DOM.
2. Git e GitHub: commits, branches e README.
3. SQL/PostgreSQL: tabelas, relações, joins, constraints e transações.
4. APIs e Node.js: HTTP, validação, autenticação e erros.
5. React e Vite: componentes, estado, formulários e consumo de APIs.
6. Supabase: Auth, Database, Storage, RLS e migrations.
7. Testes, segurança, publicação e documentação.

## Projetos de prática
Página com formulário; banco de clientes/pedidos; API CRUD; painel React; aplicação com login e dados privados.

Rotina sugerida: três sessões semanais, cada uma com um conceito, um exercício e revisão. Entender o código antes de copiá-lo.
