# Checklist de Entrega de Projeto

## Requisitos
- [ ] Todos os requisitos aprovados foram implementados.
- [ ] Itens fora do escopo estão identificados.
- [ ] O cliente revisou o resultado ou existe um processo de aceite definido.

## Interface e experiência
- [ ] Layout funciona em celular, tablet e computador.
- [ ] Formulários mostram erros compreensíveis.
- [ ] Estados de carregamento, vazio e erro foram considerados.
- [ ] Contraste, navegação por teclado e rótulos básicos foram verificados.
- [ ] Imagens e textos foram revisados.

## Qualidade técnica
- [ ] Fluxos principais foram testados.
- [ ] Não há erros conhecidos bloqueadores.
- [ ] Validações importantes também ocorrem no servidor.
- [ ] Permissões foram testadas com usuários diferentes, se aplicável.
- [ ] Segredos não estão no código público.
- [ ] Logs não expõem dados sensíveis.
- [ ] Dependências e licenças foram verificadas.

## Publicação e manutenção
- [ ] Variáveis de ambiente estão documentadas sem revelar valores secretos.
- [ ] Backups e recuperação foram considerados quando há dados persistentes.
- [ ] Domínio, hospedagem e custos recorrentes estão claros.
- [ ] Instruções de execução e implantação foram documentadas.
- [ ] Responsável por suporte e manutenção foi definido.

## Entrega ao cliente
- [ ] Acesso é entregue por método seguro.
- [ ] Manual ou orientação básica foi fornecido.
- [ ] Limitações conhecidas foram comunicadas.
- [ ] Próximos passos e canal de suporte estão definidos.
