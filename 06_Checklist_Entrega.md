# Checklist de Entrega
## Funcionalidade
- [ ] Requisitos acordados implementados.
- [ ] Formulários e validações testados.
- [ ] Botões, links e navegação funcionam.
- [ ] Estados de erro, carregamento e vazio tratados.
- [ ] Fluxos críticos testados de ponta a ponta.

## Interface
- [ ] Funciona em celular e desktop.
- [ ] Texto legível, contraste e foco adequados.
- [ ] Imagens e links sem falhas.

## Segurança
- [ ] Nenhum segredo no frontend ou repositório.
- [ ] Permissões verificadas no backend/banco.
- [ ] RLS revisada quando aplicável.
- [ ] Logs não revelam tokens ou dados sensíveis.

## Publicação e entrega
- [ ] Variáveis configuradas por ambiente.
- [ ] Build de produção validado.
- [ ] HTTPS e domínio verificados.
- [ ] Backups/recuperação avaliados para sistemas com dados.
- [ ] Cliente recebeu instruções, acessos e condições de suporte.
